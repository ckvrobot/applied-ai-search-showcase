# 🚀 Applied AI Search & Engineering Showcase

Интерактивная витрина прикладных решений, созданных автономными ИИ-агентами в среде IDE: от парсинга e-commerce и расчетов сопротивления материалов (МКЭ) до мобильной CRM-коммуникации на Авито и автономных Split-Screen каталогов.

[https://ckvrobot.github.io/applied-ai-search-showcase/](https://ckvrobot.github.io/applied-ai-search-showcase/)

## 📌 О проекте

В данном репозитории собраны результаты решения более **50 реальных прикладных задач** (строительство, инженерные системы, закупки оборудования, подбор текстиля и наем мастеров), выполненных с использованием ИИ-агентов нового поколения.

В отличие от стандартных текстовых чат-ботов, агент в IDE работает как **цифровой инженер полного цикла**:
1. **Инженерный расчет и сопромат:** расчет пространственных ферм навеса методом конечных элементов (библиотека `Pynite`) под нормативную снеговую нагрузку **350 кг/м²**.
2. **Компьютерное зрение (HSV Vision):** пиксельный анализ оттенков и гармоничный подбор пар в каталоге штор.
3. **Цеховая экономика и раскрой:** учет реальных технологических допусков швейного цеха, сокративший закупку ткани в 2 раза.
4. **Обход антифродов без капч:** автоматизация поиска и переписки с мастерами через официальное мобильное приложение Android (`UIAutomator2`).
5. **Zero-Dependency Delivery:** генерация единых автономных HTML-каталогов (Base64), открывающихся офлайн на смартфонах и ПК.

## 🛠️ Как это запускается локально

Все каталоги и 3D-модели полностью автономны и не требуют установки backend-серверов или баз данных. Достаточно открыть любой `index.html` в браузере.

Для локального просмотра всего портала:
```bash
python -m http.server 8000
```
И перейти по адресу: `http://localhost:8000`
